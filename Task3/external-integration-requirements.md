# Требования к внешним интеграциям

## Требования к безопасности

| № | Требование |
| --- | --- |
| 1 | Партнёрская платформа не получает прямой доступ к внутренним БД и сервисам PropDevelopment. Обмен идёт только через интеграционный адаптер. |
| 2 | Передаются только данные, необходимые для операции: идентификатор собственника, дом, помещение, устройство, действие и статус операции. |
| 3 | Доступ к домофону и шлагбауму проверяется по правам собственника, дому, помещению, устройству и типу действия. |
| 4 | Все сетевые соединения между PropDevelopment и партнёром защищаются TLS. |
| 5 | Действия открытия, изменения прав доступа, ошибки авторизации и ответы партнёра журналируются. |
| 6 | Биометрические данные и номера автомобилей обрабатываются как чувствительные данные; сбор и передача выполняются только при согласии пользователя и в минимальном объёме. |
| 7 | Запросы к API партнёра должны быть идемпотентными для команд управления доступом. |

## Аутентификация и авторизация

| № | Требование |
| --- | --- |
| 1 | Собственник проходит аутентификацию в текущем мобильном приложении PropDevelopment по OpenID Connect / OAuth 2.0; учётные данные пользователя партнёру не передаются. |
| 2 | Для взаимодействия сервисов PropDevelopment с платформой партнёра используется OAuth 2.0 Client Credentials. |
| 3 | Для server-to-server канала между интеграционным адаптером и партнёром используется mTLS. |
| 4 | Токены доступа должны иметь срок жизни, audience и scopes для конкретных операций с устройствами. |
| 5 | Авторизация операции выполняется на стороне PropDevelopment до отправки команды партнёру. |

## Взаимодействие систем

| № | Требование |
| --- | --- |
| 1 | Собственник выполняет действие в мобильном приложении: открыть домофон, управлять шлагбаумом или настроить разрешённый доступ. |
| 2 | Мобильное приложение отправляет запрос в `tenant-core-app`. |
| 3 | `tenant-core-app` проверяет права собственника и передаёт команду в `smart-home-integration-adapter`. |
| 4 | Интеграционный адаптер вызывает API партнёрской платформы и сохраняет технический результат операции. |
| 5 | Платформа партнёра управляет домофоном и шлагбаумом, затем возвращает статус операции. |
| 6 | События от партнёра принимаются только через интеграционный адаптер. |
